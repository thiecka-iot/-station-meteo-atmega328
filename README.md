# 🌡 Station Météo Connectée — ATmega328

## Description
Station météo avec serveur web embarqué.
Mesure la température et l'humidité en temps réel
avec un capteur DHT11 et un microcontrôleur ATmega328.

## Matériel utilisé
- Microcontrôleur ATmega328 (Arduino Uno)
- Capteur DHT11 (température + humidité)
- LED d'alerte (si température > 30°C)
- Résistance pull-up 10kΩ

## Logiciels
- Arduino IDE
- Proteus ISIS (simulation du circuit)
- Bibliothèque Adafruit DHT

## Fonctionnalités
- Lecture température toutes les 2 secondes
- Lecture humidité toutes les 2 secondes
- Alerte LED si température dépasse 30°C
- Détection d'erreur capteur automatique
